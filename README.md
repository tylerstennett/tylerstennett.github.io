# tylerstennett.github.io

Personal academic website of Tyler Stennett, PhD student in Computer Science at the Georgia Institute of Technology. Built with Jekyll (custom hand-written theme) and deployed via GitHub Pages at https://tylerstennett.github.io.

## Local development

```sh
bundle install
bundle exec jekyll serve --livereload
# → http://localhost:4000
```

Requires Ruby 3.3 — see [CLAUDE.md](CLAUDE.md) for one-time setup on macOS, project structure, and repository conventions (conventional commits, `feat/` branch naming).
